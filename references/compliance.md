# 中国地图 / 九段线 合规规范与技术实现

> 本文档是 insigoo-designer skill 的规范依据与技术细节。生成任何对外发表的中国地图前必读。
> 目标：产出的地图至少达到「可申请审图号」的合规标准；正式发表前请走第六节流程。

## 一、政策合规底线

依据自然资源部《公开地图内容表示规范》（自然资规〔2023〕2号）及标准地图服务：

1. **九段线（南海断续线）是原则性问题**。第 4 段、第 7 段与曾母暗沙、黄岩岛的位置关系必须准确。**禁止手绘近似坐标**。
2. **南海诸岛必须表示**：东沙、西沙、中沙、南沙群岛 + 曾母暗沙、黄岩岛。实践中用右下角**方形附图**表示。
3. **中国版图完整**：台湾、港澳为中国领土，必须包含在版图内（着色可标"无数据"灰）。
4. **公开发表建议使用带审图号(GS)的标准地图**，或送审取得审图号。官方来源：自然资源部标准地图服务网 `bzdt.ch.mnr.gov.cn`。
5. **无九段线的中国地图不得对外发表/交付。**

## 二、数据源选择（诚实对比）

| 方案 | 数据源 | 坐标合规性 | 说明 |
|------|--------|------------|------|
| **本 skill 采用** | `frykit` + `frykit_data` | 高 | 坐标源自官方标准地图，按 WGS84 校准；`add_cn_line()` 出标准九段线。适合程序化出图、快速合规 |
| 备选（最稳） | GS(2019)1719 号 GeoJSON | 最高（自带审图号） | 直接读入即可作为「已审」底图；对审图号有硬要求的正式出版物首选 |
| 备选 | DataV `100000_full.json` | 中 | 阿里云公开数据，含 `100000_JD` 南海诸岛，但**无审图号背书**，发表前仍需送审 |

**为什么用 frykit**：一行 `add_cn_line()` 出标准九段线，一行 `add_cn_province()` 出标准省界，无需自己处理坐标，最省心且坐标合规。但注意：**程序生成的图仍需按第六节送审才能正式发表**——frykit 保证的是坐标正确，不替代审图号。

## 三、"双地图"错误详解（最常踩的坑）

**现象**：一张中国地图里出现两幅中国地图——主图一幅，右下角附图里又一幅缩小的全国图。

**根因**：
- `frykit.add_mini_axes(ax)` 不传 extent 时，默认把**整幅中国**塞进小框；
- 或主图 `ylim` 下界给到 3.5°N，主图自己就画了大片南海空白，再加附图 = 视觉上两幅。

**正确做法**（本 skill 已内置）：
1. 主图 `ylim` 下界收到 **14°N**（保留海南岛完整，南海空白区不进主图）；
2. 附图用 `ax.inset_axes()` 手动定位，并 **严格 `set_xlim(105.8,123)` / `set_ylim(2.5,24.5)`**，只显示南海方形区（含广东/广西/海南南部一小段大陆海岸线）；
3. 附图加边框 + "南海诸岛"标注。

## 四、中文字体防乱码

**现象**：地图标注中文全变方块 □□□。

**根因**：依赖 `matplotlib.font_manager` 缓存搜索字体名，在沙箱/无缓存/新环境下找不到。

**修法**：直接指定字体文件**绝对路径**，用 `FontProperties(fname=...)`：
```python
FONT_PATH = r"C:\Windows\Fonts\msyh.ttc"   # Windows 微软雅黑
# macOS: /System/Library/Fonts/PingFang.ttc
# Linux: /usr/share/fonts/.../NotoSansCJK-Regular.ttc 或 wqy-microhei.ttc
fp = FontProperties(fname=FONT_PATH, size=14)
ax.set_title("标题", fontproperties=fp)
```
本库 `get_cjk_font()` 已封装多平台候选路径自动探测。

## 五、配色规范与铁律

| 数据类型 | 归一化 | colormap | 说明 |
|----------|--------|----------|------|
| **全正值·右偏数据**（总量/计数，中位数<<最大值） | `log1p` 压缩 | **`YlOrRd` 暖色**（奶油白→黄→橙→深红） | ⚠️ **绝不用 `RdYlGn_r`**！右偏数据下 70%+ 面积挤在绿色端→全图绿、高低量无法区分。YlOrRd 视觉层次清晰 |
| 全正值·近似均匀（密度/p95 截断后） | `Normalize(vmin,vmax)` 或 `vmax=p95` | 顺序色（蓝→红橙自定 / `YlOrRd`） | p95 做 vmax 让色阶铺满，避免大部分区域挤在低端 |
| 有正负（增长率） | `TwoSlopeNorm` 以 0 为中心 | `RdYlGn_r` 发散 | 正=红、负=绿（注意：这里遵循数据方向，不是股市涨跌） |
| 深色主题（热力密度） | 同上 | 蓝深→青→黄→红橙渐变 | 海底深色，文字浅色 |

**关键铁律**：
1. 全正值数据**禁止**用发散色（`diverging`/`TwoSlopeNorm`），否则色标一半浪费在不存在的负值区。
2. **右偏数据必须用 `YlOrRd` 暖色 + `log_scale=True`**——这是地图可读性最核心的一条。
3. 不确定数据分布时，宁可用顺序色 `YlOrRd`，也不要赌发散色。

## 六、如何取得审图号（发表前必读）

程序化生成的地图**不能直接当已审图发表**。两条合规路径：

**路径 A（推荐，省事）**：直接用标准地图服务
- 到 `bzdt.ch.mnr.gov.cn` 下载所需比例尺的标准地图（自带 GS 审图号）；
- 在图上叠加你的数据/标注，并**保留原审图号、注明来源**；
- 这种方式无需再送审。

**路径 B（程序化出图后送审）**：
- 用本 skill 保证坐标合规（九段线位置、版图完整、南海附图）；
- 通过自然资源主管部门的地图审核渠道送审，取得审图号后在图上标注；
- 适用于需要高度定制化、标准地图服务没有的专题图。

> 本 skill 的价值是：**让你在送审前就画出坐标正确的底图**，把审图退回的风险降到最低。

## 七、地理正确长宽比（防压扁）

中国位于中纬度，1° 经度实际长度 ≈ 1° 纬度的 `cos(34.5°)≈0.824` 倍。
- `set_aspect('equal')` 把经纬度当等长 → 中国被横向拉成约 **1.51:1 扁形**（错误）；
- 本库 `geo_aspect(extent)=1/cos(中纬度)≈1.21` → 标准竖版形状（正确）。

主图务必 `ax.set_aspect(geo_aspect(extent))`。

## 八、常见错误 → 修法（实战经验）

| 现象 | 根因（通用经验） | 修法 |
|------|------|------|
| 一张图两幅中国地图 | 附图未限定 extent | 用 `add_nanhai_inset`（已内置 xlim/ylim 限定）或手动 set_xlim/ylim |
| 九段线中文变方块 | 依赖 fontManager 缓存 | 用 `get_cjk_font()`（绝对路径字体） |
| 手绘九段线不合规 | 自己近似坐标 | 用 `frykit.add_cn_line()`（官方标准） |
| 色标一半浪费在负值区 | 全正数据用了发散色 | 全正值别用 `diverging`，用默认顺序色 `YlOrRd` |
| 附图飘太远/太大 | add_mini_axes 自动定位不稳 | 用 `add_nanhai_inset` 手动 rect 定位 |
| **地图被横向拉扁** | 主图 `set_aspect('equal')` | 用 `geo_aspect(extent)=1/cos(中纬度)` |
| **省界盖住专题填色** | `add_cn_province` 用了 `fc` 填充 | 专题图必须 `fc="none"` 只描边；先画专题 choropleth 再描省界 |
| **南海附图大陆段空白** | `add_nanhai_inset` 没传专题图层 | 传 `layer_gdf`/`layer_column`/`layer_cmap` 等，附图内也叠加专题 choropleth |
| **全图绿/高低量同色** | 数据右偏（如中位数<<最大值）用了 `RdYlGn_r`，70%+ 面积挤在绿色端 | **总量类指标用 `YlOrRd` 暖色**；RdYlGn_r 仅用于有明确正负含义的数据 |
| **把省界图当专题图交付** | 用 frykit 省界填省份数值，伪装成"流域/生态区分布图" | 省界 ≠ 专题界。必须叠加**真实的专题 SHP/GeoJSON**（见 SKILL.md「叠加自有专题图层」），省界只作衬底 |

## 十、frykit 常用 API

```python
import frykit.plot as fplt
import frykit.shp as fshp

fshp.get_cn_province_geodataframe()   # 省界 GeoDataFrame（列: province_adcode, province_name, geometry）
fplt.add_cn_province(ax, fc=颜色列表, ec="#999", lw=0.4)   # 画省界+着色
fplt.add_cn_line(ax, lw=1.2, ls="--", color="#CC0000")     # 画九段线（标准）
fplt.add_mini_axes(ax, shrink=0.25)   # 自动南海附图（⚠️ 不限 extent 会双地图，本 skill 不用它，改手动 inset）
```

`fc` 颜色列表顺序必须与 `get_cn_province_geodataframe()` 的行顺序一致——用 `province_adcode_order()` 对齐。
